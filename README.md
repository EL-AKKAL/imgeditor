# Image Editor v2

Welcome to **Image Editor v2** — the next evolution of our image editing app!

## New Features in v2

- 🎨 **Stickers**  
  Add expressive emoji stickers anywhere on your image for personalized fun and creativity.

- 🌈 **Hue Adjustment**  
  Fine-tune the colors of your image by rotating the hue to get the perfect tone and mood.

- 🌡️ **Temperature Control**  
  Warm up or cool down your photo by adjusting the color temperature for more natural or stylized looks.

---

## Installation

```bash
git clone <your-repo-url>
cd your-project-folder
npm | yarn | bun install
npm run dev
```
